# Data Storage mockups

Open `index.html` in a browser (no build, no server). Standalone: it does not import app code.

- **Design:** A · Clean, B · Layered, C · Dense (top bar).
- **State:** Normal, Success, Warning, Empty / no older data, Browser demo (top bar).
- **Sections:** 1 Location, 2 Folders, 3 Backup & library, 4 Older data & files.

Text and paths come from `src/components/adboard/desk/storage-panel.tsx` and `data-storage.tsx`. Colours come from `src/app/globals.css`. Delete `mockups/` to remove everything.
