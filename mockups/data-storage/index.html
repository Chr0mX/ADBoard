Backup & library

Back up copies the whole data folder. Export and import use one library file.

adboard-library.json holds everything: touch macros, Shell Automation scripts, apps, variables, groups, profiles, the queue, schedules and per-phone macro choices. One macro or script is exported from Macros or the Shell Library.

Import adboard-library.json: add it to the current library, or replace the library with it? The current data is backed up first either way.

Which files can I edit by hand?

Safe to edit or copy in while ADBoard is closed (a file that can't be read is moved to backups\corrupt and reported):

  • macros\<Name>.json
  • shell_scripts\<Name>.json
  • shell_scripts\_library.json
  • config\user_config.json

Don't edit (ADBoard manages them):

  • config\.revisions.json
  • config\auth.json
  • backups\history\
